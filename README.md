# SoEasy 题库采集器

把 SoEasy 小程序练习页面上的题目整理成可阅读、可继续补充的题库。程序自动截图，用本地 OCR 识别题号、题干和选项，点击选项及“查看答案”取得答案，保存后进入下一题，最后生成包含**题号、题目、全部选项和正确答案**的 Word 文档。

支持**单选题、多选题、判断题**，三种题型分别保存。采集时有实时 OCR 文字窗口，方便查看当前识别结果。OCR 模型随软件提供，识别在本机完成。

## 下载和启动

适用于 **Windows 10 / 11 64 位**。稳定版 **1.2.1** 保留，新精简包作为 **1.2.2-beta.1 预发布版**提供：

| 版本 | 下载 |
| --- | --- |
| 稳定版 1.2.1 | [下载稳定版](https://github.com/Mrchips233/soeasy-question-bank/releases/tag/v1.2.1) |
| 精简 Beta 1.2.2-beta.1 | [下载预发布版](https://github.com/Mrchips233/soeasy-question-bank/releases/tag/v1.2.2-beta.1) |

1. 登录你的 GitHub 账号，打开上方对应版本的下载页面，在 **Assets** 中下载 Windows 压缩包。
2. 将压缩包**完整解压**到桌面或其他可写文件夹，双击 `SoEasy题库采集器.exe`。无需安装 Python、uv，也无需另行下载 OCR 模型。
3. 保留 EXE 同目录下的 `_internal` 文件夹。不能只复制 EXE，也不要直接在压缩包里运行。

Beta 版可解压到独立文件夹试用，先试采集并检查输出结果。

## 第一次采集

1. 打开小程序的练习页面，把窗口放在**主屏幕**。让题号、完整题干、全部选项和底部按钮同时可见；关闭已打开的答案弹窗。
2. 在采集器选择与当前页面一致的**题型**，再选择**输出目录**。不同课程或不同题库请使用不同目录。
3. 单选题和多选题按页面设置**每题选项数**，默认 4；选项数量不固定时选 0 自动识别。判断题固定为 2。
4. 点击 **1 框选小程序区域**，从小程序内容顶部拖到最底部按钮后松开。不要框入 Windows 标题栏或任务栏。窗口移动、缩放或换电脑后，需要重新框选。
5. 点击 **2 仅识别当前题**。主窗口会最小化，模型加载后留出 3 秒将小程序切到前台；在实时 OCR 窗口核对题号、题干和选项。这一步只读取，不答题。
6. 点击 **3 试采集 3 题**。模型加载后留出 5 秒将小程序切到前台，程序随后自动点击并采集。
7. 试采集结束后点击 **打开输出目录**，检查当前题型的 Word。确认内容正确后关闭 Word，再点击 **采集到最后一题**。程序从小程序当前显示的题目向后采集，默认跳过已经保存的题号。

采集中保持小程序可见，避免遮挡或移动窗口，暂时不要同时操作鼠标点击题目。页面切换较慢时，把**界面等待秒数**从默认 0.6 调到 1～2 秒。

## 查看结果和停止

- **实时 OCR** 窗口自动显示最近一次识别的原文，可点击“复制当前文字”或“隐藏”；主窗口的“实时 OCR”按钮可以再次打开。屏幕没有足够空位时，该窗口会暂时隐藏。
- 按 **Esc**、把鼠标移到屏幕左上角，或点击主窗口“停止”/实时窗口“停止采集”即可停止。等待保存结束后再关闭软件。
- JSON 每成功采集一题立即保存；Word 每采集 10 题更新，并在结束或停止时导出。点击 **重新导出已有题库** 可从 JSON 再生成当前题型的 Word。
- 程序到最后一题停止。前面缺少的题不会自动返回补齐，可先在小程序中返回缺失题，再继续采集。

默认输出目录是 EXE 同级的 `output`，也可自行选择。以下路径都相对于所选输出目录：

| 题型 | Word 文档 | 采集记录 |
| --- | --- | --- |
| 单选题 | `单选题库.docx` | `题库.json` |
| 多选题 | `多选题/多选题库.docx` | `多选题/题库.json` |
| 判断题 | `判断题/判断题库.docx` | `判断题/题库.json` |

**JSON 用来继续采集、保存采集记录和重新导出 Word，请保留。** 每个题型目录还会保存题目/答案截图，以及排查识别问题的日志。

## 修正一题或重新采集

- **只改一题：**在小程序中跳转到该题并关闭答案弹窗，选择对应题型与原输出目录，点击 **重采当前题**。成功后替换该题、更新 Word，然后停止，其他题保留。
- **批量重采：**回到要重采的起始题，勾选 **重新采集并覆盖已有题（保留其他题）**，再试采集或采集到最后一题。
- **继续补充：**不勾选覆盖，使用原目录继续运行，已经保存的题号会跳过。下次启动时覆盖开关默认关闭。

覆盖前程序会自动备份 JSON 到该题型目录的 `backups`，新记录成功保存后才替换旧记录。无需为了重采删除 `题库.json`。

## 使用时留意

窗口需要同时显示全部题目与选项，程序不会自动滚动，也不会把题目中的图表或公式图片转成文字。OCR 可能误读，建议先试采集检查 Word，发现问题后重采。

程序会实际选择练习选项，可能影响小程序的答题记录。取得明确答案时按答案保存；如果连续两次点击“查看答案”都没有检测到错误，会按本次所选选项正确保存，建议结合保留的截图核对这种记录。

遇到识别失败时，已完成题目仍会保存在 JSON 中。可点击 **打开调试日志** 查看本次记录，调整窗口或等待秒数后继续。Word 正在打开时，程序可能另存带时间戳的文件；需要更新原文件时，先关闭 Word，再重新导出。
