# SoEasy 题库采集器

当前版本：**1.2.1**。适用于 **Windows 10 / 11 64 位**，解压即可运行，无需安装 Python 或 uv。

程序从已打开的小程序界面采集题目，使用本地 OCR 识别题号、题干、选项和答案，生成 JSON 题库及 Word 文档。支持单选题、多选题和判断题，并提供实时 OCR 文字窗口。

## 下载与运行

1. 登录拥有此私有仓库访问权限的 GitHub 账号，打开仓库的 **Releases** 页面。
2. 下载 `SoEasy_1.2.1_Windows_x64.zip`，将压缩包**完整解压**到可写目录。
3. 保留 `SoEasy题库采集器.exe` 同目录下的 `_internal` 文件夹，双击该 EXE 启动。
4. 打开题目界面，选择对应题型和输出目录，重新框选小程序区域，再开始采集。

换电脑或调整小程序窗口大小后，需要重新框选采集区域。采集中请保持题目窗口可见，避免其他窗口遮挡。

## 输出文件

不同题型分别保存，切换题型不会覆盖其他题型的题库：

| 题型 | Word 文件（相对于所选输出目录） |
| --- | --- |
| 单选题 | `单选题库.docx` |
| 多选题 | `多选题/多选题库.docx` |
| 判断题 | `判断题/判断题库.docx` |

Word 中包含题号、题目、选项和正确答案。JSON 用于保存采集记录和继续采集；截图、日志及 JSON 也按题型分开存放。

## 1.2.1 的识别与核对

- 页面核对以题号数字为依据，总题数辅助检查；不再因两次 OCR 的题干、选项文字或行数不一致而中断。
- 题干、选项仍完整识别并保存，分区增强失败时使用原识别结果。
- 保留两次“查看答案”，并处理“下一题”点击未生效的情况。
- 修复多选第 199 题的弹窗遮挡：确认进度数字被弹窗覆盖后，忽略残缺进度，使用上方清晰的题号核对，避免将 `199/260` 误读为 `99/260` 后停止。

## 离线与文件校验

OCR 使用随软件附带的 RapidOCR / ONNX Runtime 和 PP-OCRv5 模型，全程在本地运行，无需联网下载模型或调用云端 OCR。

安装包不包含个人配置、已采集题库或个人运行日志。本仓库只存放发布说明及安装包校验值，安装包位于 Releases 附件。

下载后的 SHA-256 应与 [SHA256SUMS.txt](SHA256SUMS.txt) 一致。可在 PowerShell 中运行：

```powershell
Get-FileHash -LiteralPath '.\SoEasy_1.2.1_Windows_x64.zip' -Algorithm SHA256
```

具体变更和验证范围见 [RELEASE_NOTES.md](RELEASE_NOTES.md)。
