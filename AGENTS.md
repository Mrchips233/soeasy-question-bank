# Project workspace

Keep all work for this project inside this repository directory. Do not create
project folders, backups, reports, downloads, or build output in its parent
directory or another study/work directory.

Put temporary work, test results, build caches, release artifacts and release
backups under `.work/`, which is ignored by Git. Keep current application source
files in the repository root.

Preserve local configuration, collected question banks and evidence unless the
user explicitly requests their deletion. Publish only application source and
original public test samples; never commit personal configuration, real question
bank data, private screenshots, logs, virtual environments or `.work/`.

Do not remove existing GitHub release records without an explicit request.
